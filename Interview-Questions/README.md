# Interview Questions

Cross-topic and scenario-based questions for self-testing. Topic-specific Q&A lives on each topic page; these pages focus on **comparisons, "which would you use" scenarios, and rapid-fire recall**, and link back to the topics instead of repeating them.

| File | Focus |
|---|---|
| [SOLID Questions](SOLID-Questions.md) | Spotting violations, principle interplay, trade-offs |
| [Design Pattern Questions](Design-Pattern-Questions.md) | Pattern selection scenarios, comparison table |
| [Core LLD Questions](Core-LLD-Questions.md) | OOP, relationships, approach to LLD rounds |

## How to Practice
1. Cover the answer and say yours **out loud** in under 60 seconds.
2. If you can't, follow the link to the topic page and re-read its Key Takeaways.
3. For scenario questions, name the **problem**, the **pattern/principle**, and **one trade-off**.
